The goal of this project is to classify performance metrics and system objectives for a three-axis CubeSat Attitude Determination and Control System (ADCS). The system will be evaluated through a hardware-in-the-loop (HIL) testbed as well as an on-ground physical demonstration.

This project was started at the beginning of the 2026 spring semester and is currently in 
progress, with the Python simulation complete and FPGA IMU emulation nearly complete (physics engine and SPI interface independently validated, register map interface/CDC protocol in progress). Check out docs for more details.
